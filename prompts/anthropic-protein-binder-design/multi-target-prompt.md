If controls exist but (b) fails on every instrument, self-authorization is barred: (1) re-run the control with control-ligand MSA enabled, (2) try an alternative co-folder, (3) try AF_Unmasked with template injection; a geometry-only or pose-only score without demonstrated positive-control separation fails (b) by definition.
2. Control selection: Prefer a non-antibody protein control (natural ligand, receptor or co-receptor ectodomain, viral entry protein, peptide); co-folding models systematically underperform on antibody-antigen interfaces, so an antibody or nanobody is a SECONDARY control. 3. MSAs: Stage target-chain MSAs once per target (ColabFold MSA server or local MMseqs2) into a shared per-target cache during TOOL-BRINGUP; every MSA-consuming arm reads from this cache rather than re-querying per call. Single-sequence mode for an MSA-capable arm is a per-target deviation taken only when it clearly outperforms target-MSA on that target's control set, and is disclosed.
4. Rank by ipSAE_min (definition and union-mask multimer construction in the ipSAE_min definition below). Track ipTM and LIS as free shadow metrics from the same forward pass; ranking uses ipSAE_min only. 5. z-score is transductive (μ, σ depend on the scored pool): comparable only within the batch used to calculate it (incomparable across targets, waves, or campaigns).
